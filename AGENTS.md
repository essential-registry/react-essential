# React Essential: guide for AI agents

React 19 + Vite + TypeScript + Tailwind v4 SPA starter. TanStack Router (file routes) and Query, Base UI components (shadcn style), zod env and API client, vitest, oxlint and oxfmt.

## Commands

```bash
pnpm install
pnpm dev                 # http://localhost:5173
pnpm typecheck           # tsc --noEmit
pnpm lint                # oxlint (type-aware)
pnpm format:check        # oxfmt --check
pnpm test                # vitest run
pnpm build               # tsc + vite build
pnpm gen:feature <name>  # scaffold src/features/<name>
pnpm build:prepare       # fix, format, typecheck, test, build
```

The gate is `pnpm run ci (non-mutating) / pnpm run build:prepare (fixes first)`. CI runs the same thing, so a change that passes locally passes in CI.

## Layout

```text
src/
  routes/      TanStack Router file routes (__root.tsx, index.tsx); routeTree.gen.ts is generated, never edit
  features/    <domain>/  index.ts (public API), schemas.ts (zod = source of types), api/, components/, hooks/
  components/  shared UI; components/ui = Base UI primitives
  providers/   theme, query client, head (app-providers.tsx)
  hooks/       shared hooks
  lib/         env.ts (validated VITE_* env), api.ts (typed fetch), utils.ts
  styles/      root-layout.css (Tailwind v4 theme tokens)
tests/         vitest setup
docs/          guides
```

## Conventions

- Layers point down only: `routes` -> `features` -> `components`/`lib`/`providers`. A feature never imports another feature's internals, only its `index.ts`.
- Routes are thin: they compose features. Data fetching goes through TanStack Query and `lib/api.ts` (responses parsed with zod).
- Read env only through `src/lib/env.ts` (`VITE_*` variables). Add new ones to the schema, `vite-env.d.ts` and `.env.example`.
- Types come from zod schemas. No `any`.
- UI primitives use Base UI (`@base-ui/react`) styled with Tailwind and `cva`.
- Files are kebab-case, components PascalCase, tests sit next to the code as `*.test.ts(x)`.

## Rules (all Essential templates)

- **Git:** commits and pushes use the user's own git identity. Never set a Claude identity and never add `Co-Authored-By` or "Generated with" lines. Do not commit unless asked.
- Never read or print `.env` files or secrets. Every setting has an entry in `.env.example`.
- Conventional commits (`feat(scope): ...`). Feature branch, then pull request.
- Business numbers (limits, durations, thresholds) are configuration, never constants in code.
- If a rule is missing, stop and ask. Do not invent one.
- Run the gate before saying "done".

## Never

- Edit `src/routeTree.gen.ts` by hand (it is generated by the router plugin).
- Edit `pnpm-lock.yaml` by hand.
- Disable lint rules to make the gate pass.
- Read or print `.env` values.
