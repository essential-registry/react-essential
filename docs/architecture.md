# Architecture

React Essential is a single-page app organised by feature.

```text
routes/  ->  features/  ->  components/ , lib/ , providers/
```

Imports only point down the arrow.

- **Routes** (`src/routes`): TanStack Router file routes. Keep them thin; they compose features. `routeTree.gen.ts` is generated by the router plugin during `dev` and `build`.
- **Features** (`src/features/<name>`): one product area. Public API through `index.ts`; other code imports `@/features/<name>` only. `schemas.ts` holds zod schemas, the source of types. Create one with `pnpm gen:feature <name>`.
- **Data**: TanStack Query for server state; `lib/api.ts` fetches JSON and validates it with a zod schema.
- **UI**: `src/components/ui` are primitives built on [Base UI](https://base-ui.com), styled with Tailwind v4 tokens in `src/styles/root-layout.css`.
- **Providers**: `providers/app-providers.tsx` wires theme, document head (unhead) and the query client. The theme provider toggles the `dark` class on `<html>`.
